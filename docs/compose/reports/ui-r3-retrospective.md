## 二、Token 与往返消耗复盘

会话总工具调用约 **65 次**。按性质拆分：

| 类别 | 次数 | 占比 | 是否必要 |
|---|---|---|---|
| **无用的读图取证** | ~6 | 9% | ❌ 浪费（预览通道错位，2 次后仍继续读） |
| **工具链从零摸索**（chrome→CDP→WS→server 回收） | ~10 | 15% | ❌ 浪费（应先检索） |
| **一次性脚本自身 bug 返工**（硬编码 hash／正则漏字符／占位符语法） | ~4 | 6% | ❌ 可避免 |
| **列宽多轮迭代**（改→生成→启浏览器→全矩阵 ×3） | ~6 | 9% | ❌ 可压到 1 轮（先算预算） |
| **锚点匹配失败**（签名漏 `-> str` 等） | ~3 | 5% | ❌ 可避免 |
| 需求澄清/方案选择（用户交互） | ~3 | 5% | ✅ 必要 |
| 有效实现 + 验证（改码/取证/测试/截图） | ~33 | 51% | ✅ 必要 |

**浪费合计约 29 次调用（45%）**。用户反馈的"第一步耗 41% token"与此吻合。

## 三、五类典型错误与根因

### 1. 证据形态选择错误（最贵）
- **现象**：预览通道返回错位图像，我用 md5/sha 比对、注入标记取证、受控复读等手段反复确认，共约 6 轮。
- **根因**：把"我看到的图像"当第一手证据。图像经多级通道传输不可靠，而 **DOM 计算样式/几何是程序化可取的确定性数据**。
- **对策**：证据分级固定为 程序化断言 > 数值输出 > 图像内容。UI 判断禁用第三级。

### 2. 开工不检索，工具链从零造
- **现象**：截图卡住后连续试 `chrome --screenshot` 两种模式、Node WS 客户端、CDP 启停时序、user-data-dir 等。
- **根因**：没有先问"这个环境/项目里以前怎么做的"。实际项目内已沉淀管线，只是本轮未检索。
- **对策**：每轮**首次调用**固定为检索动作。写进 MEMORY Rules 2。

### 3. 未核对"确认稿 vs 生产 DOM"的结构差异
- **现象**：确认稿 `.spacer{flex:1}` 看着合理，直接搬到生产 CSS → 生产每组 1 个 spacer（共 4 个）全部伸展 → 侧栏组间 283px 空白，用户两次反馈才定位。
- **根因**：把确认稿当"纯样式稿"，忽略它是手写简化 demo，DOM 数量与生产不同。
- **对策**：照抄任何 class 样式前，先 `grep -c` 双方同名 class 数量。

### 4. 一次性脚本无自检，失败静默传导
- **现象**：① 硬编码 vendor hash `self@d5d45d7a`，改 CSS 后 hash 变化 → CSS 静默外链 → 整页无样式，但断言缺失，几何数据全部失真，白测 3 轮；② 正则漏收尾 `">` → 替换 0 次仍继续跑；③ JS 模板占位符语法错 → 返回 `{}`。
- **根因**：脚本"跑完即用"，没有 fail-fast。
- **对策**：生成类脚本必须 ① 禁硬编码会变值 ② 断言替换次数 ③ 打印关键输出。

### 5. 几何问题"看图调参"而非"先算后改"
- **现象**：列宽迭代 3 轮，每轮完整链路（改 CSS→生成 HTML→启 Chrome→6 场景矩阵）。
- **根因**：没有先算「右栏可用宽 = 视口 − 侧栏 − padding − 左树 − 间距」，而是靠截图反馈试。
- **对策**：列宽/溢出/换行类问题先列预算算式，再一次性改到位（预算式已存入 MEMORY）。
