Dataflow 链路

cache缓存层 db数据库 html渲染 / 页面 audit审计落库

链路步骤前缀 —— 每个步骤前的小色标标明该步碰的是什么资源，不是构件分类
cache青绿 —— 命中或写入缓存层（L1 进程内 / L2 Redis 快照 / API 静态文件）。
db蓝 —— 访问数据库或连接池取连接。
html橙 —— 服务端拼装 HTML 或路由分派等纯内存动作。
audit品红 —— 鉴权校验与审计落库（写入独立的 audit.db）。
无前缀的步骤 = 普通控制流（参数解析、条件判断、返回封装），不碰外部资源。

F1请求主链路（所有 HTML 页面）server.py ~:360

  1. do_GET/do_POST → _handle：urlparse → path.rstrip("/") → unquote
  2. 静态白名单命中 /static/vendor/<name@ver>/<file> → 直接读文件返回，跳过鉴权
  3. route_scan_routes 一次遍历得匹配项 + 允许方法；无匹配：有 Allow → 405，否则 404
  4. authneeds_auth → _authenticate：Cookie session_id → auth.get_session_user
  5. 失败 → 302 /login?expired=1&next=<urlquote(path)>；成功 → refresh_session（滑动 TTL 86400）+ render.set_request_user(user)
  6. dbneeds_db → get_config_db()，存 _req_conn 供本请求复用
  7. 派发给 page handler，拿 (code, html, headers)
