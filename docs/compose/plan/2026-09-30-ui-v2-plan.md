## 全局约束（每个任务都生效）

1. **不改功能语义**：路由、鉴权、URL 参数、筛选/排序/分页/导出协议、缓存与调度语义逐字不动。
2. **单一来源**：公共样式只存在于 `render._BASE_CSS` / `_COMMON_CSS`；**禁止新增页面级 `<style>` 补丁或表现性内联样式**。
3. **测试框架 `unittest`**，一切命令在仓库根 `venv` 内执行：`source venv/bin/activate`。
4. **`discover` 必须带 `-t .`**（否则测试隔离失效，会连生产 Redis）。
5. **日志/产物落仓库内已 gitignore 目录**（`run-logs/`），唯一文件名，**禁止 `rm`**；`/tmp` 会被环境清空。
6. **同一测试段执行上限 2 次**；源码变更后计数重置。
7. **每处 CSS/HTML 补丁写盘前做括号平衡与关键规则自检**（本轮已因漏 `}` 导致整段 CSS 被吞，血的教训）。
8. 用户可感知文字一律简体中文。

## 风险与回退

- **最大风险**：公共层换装 + 页面补丁下线必须在同一次改动内完成，否则旧页面 CSS 会压制新令牌，出现半新半旧。
