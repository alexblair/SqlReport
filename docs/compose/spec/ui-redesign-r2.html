修复后：单列改 minmax(0,1fr) + 主内容 min-width:0，布局宽度=390 不溢出；宽表在 .table-wrap 内横向滚动（与生产既有表格滚动语义一致）。手机屏内表格可左右滑动。

  • 侧栏 ≤1024 收 64px 图标栏（现状保持，原型一致）
  • 页头按钮换行不叠压（flex-wrap）
  • 容器 padding ≤640 收窄为 12px（现状保持）
  • 左树在窄屏下置于表格上方单列堆叠
逐页对比结论：原型 13 个页面逐页比对生产实现，11 页为结构/布局/排列级差异，仅登录页、报表中心判定一致（或仅样式）。结构级差异归为四类：
类型① 双栏卡片塌成单列平铺报表编辑、端点表单、调度新建——原型 grid-2 双栏多卡 + page-head/crumb，生产为单 card 内 form-section 单列（全仓 grid-2 仅概览一处）

类型③ 区块多出或归属挪位调度列表多「最近执行记录」表、概览品牌卡挤占右列、审计筛选/表格入 card 且按钮移位
类型④ 表格列构成缺失连接池缺「关联报表」列、用户缺「角色说明」列、报表配置右列从单表拆成 4 张分类表
