1. UI 设计一旦变更（改 `render.py` / spec），**本目录的图不随之更新**，只保留"当时版本"的事实。
2. 需要新版本的对比图时，**新建带版本后缀的目录**（如 `shots-ui-v3/`），不要覆盖或改名本目录。
