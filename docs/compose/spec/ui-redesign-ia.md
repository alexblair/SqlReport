# 信息架构与页面重构方案（ui-redesign · T3）

> 输入：`ui-redesign-inventory.md`（T1）+ `ui-redesign-analysis.md`（T2）。
> 输出：新导航模型、新旧页面映射、每页功能布局、交互收敛决策；并回填覆盖清单「新方案去向」列。
> 约束：功能零丢失（S2-A）；后端共享语义/URL 参数协议不动（S3）；允许增删页面形态与布局（S1）。
> 最后更新：2026-09-25

## 1. 设计方向（单一方向，供 T4 展开为规范）

**明亮工作台（Light Workspace）+ 深色侧栏**：数据工具 2026 主流形态。

- 左侧固定深色侧栏承载分组导航与账户区；内容区浅灰底 + 白卡片；
- 主色沿用 indigo 系（`#4f46e5` 族，与现状兼容），建立完整令牌（T4 给精确值）；
- 排版：清晰三级（页标题 / 区块标题 / 正文），数字与 SQL 用等宽；
- 状态四件套全站统一：hover / focus-visible / disabled / loading；
- 对比度按 WCAG AA；图标统一为线性字符/内联 SVG 体系，**禁用 emoji 图标**；
- 圆角、间距、阴影收敛为 4–6 档令牌。

## 2. 新导航模型（替换 `_NAV_ITEMS` 顶栏方案）

侧栏分组（自上而下）：

| 分组 | 项 | 路由 | 高亮规则 |
|------|----|------|----------|
| （品牌区） | SqlReport 品牌名 + branding 前缀 | — | — |
| 分析 | 报表中心 | `/report` | report* |
| 分析 | 报表详情（从列表进入，不占导航） | `/report?id=` | report* |
| 管理 | 概览 | `/config` | config（仅概览） |
| 管理 | 报表配置 | `/config/reports` | config-reports* |
| 管理 | 连接池 | `/config/pools` | config-pools* |
| 管理 | 用户 | `/config/users` | config-users* |
| 服务 | API 接口 | `/config/api-endpoints` | api* |
| 服务 | 定时任务 | `/config/scheduler` | scheduler* |
| 治理 | 审计日志 | `/audit` | audit* |
| （账户区·侧栏底部） | 当前用户名菜单 → 退出登录 | `/logout` | — |

要点：

- 解决 P1-1 双轨：概览卡片不再与侧栏重复——概览只做「统计+快捷入口」，入口指向同侧栏路由；

- 解决 P0-2：品牌单一来源（branding 配置 > 默认名），顶栏方案废除；
- 路由 URL 不改（书签/测试/审计路径零破坏）；`/config/categories` 等重定向保持。

## 4. 关键页面功能布局（区块顺序 = 信息优先级）

### 4.1 报表中心（`/report`）

1. 顶部：页标题 + 搜索框（按名称/备注实时过滤，客户端）+ 「新建报表」（有权限语境时仅管理员可见——保持现状无权限模型则不加）；
2. 最近查看：卡片横排（localStorage `sqlreport_recent`，空则整块隐藏）；
3. 主体两栏：左分类树（折叠记忆沿用 `cat_tree_collapsed`）+ 右报表卡片网格（名称、分类面包屑、备注摘要、⏰/♻/API 徽标纯文字化）；
4. 空态：引导三步（对应现 onboarding 文案迁移至此）。

### 4.2 报表详情（`/report?id=`）

1. 紧凑头：报表名（h1）+ 分类 + 操作组（编辑 / 导出 / 刷新重建，主次分明：刷新为主按钮）；
2. 状态横幅（仅有异常时出现）：截断护栏、写护栏、缓存不可用——人话文案（见 §5 术语表）；
3. 缓存徽标：一行轻量文案「数据更新于 X 分钟前 · 缓存 1 小时」；
4. Tab：**数据**（默认）/ **规则** / **接口** / **调试** / **备注**
   - 数据：工具行（列设置、排序、行数、分页、快速筛选行、高级筛选入口、清除）→ 表格 → 分页；
   - 规则：现「当前规则 JSON + 嵌套构建器 + 排序列表」合并页（可视化构建 + 规则预览双 tab）；
   - 接口：现 API URL 区（复制组件统一）；
   - 调试：现 Debug 区（实际 SQL、连接信息），仅 DEBUG 或管理员可见语义保持现状实现；
   - 备注：Markdown 全文 + 免责说明；**三态开关废除**，有备注时数据页顶部显示单行摘要可展开；
   - 备注为空、无 API、非 DEBUG 时对应 tab 隐藏或灰置。
5. 废除：顶部整宽「切换报表」卡（改回报表中心入口 + 头部紧凑 select）、4 条虚线折叠条（内容分入 tab/摘要）。

### 4.3 报表配置列表（`/config/reports`）

1. 顶部：搜索过滤框（保留 `initConfigFilter` 语义）+ 新增报表 / 新增分类；
2. 左栏：分类树（含新增/重命名/删除/排序，原分类管理区块整体迁入）+「未分类」节点；
3. 右栏：当前分类下报表表（checkbox、名称+徽标、连接池、缓存、备注摘要、API 计数、行内操作：查看/编辑/复制/更多菜单；删除入「更多」降低红色密度；上下移动保留但仅排序模式显示）；
4. 选中 ≥1 行时底部浮出批量操作条：设分类 / 设连接池 / 设缓存策略 / 删除（confirm 统一组件）；
5. 去除：顶部独立分类树区块与分组表头的双层重复。

### 4.4 报表编辑（`/config/reports/{id}/edit|add|copy`）

分区（`<section>` + 锚点，页内左侧分区导航或顶部 chips）：

1. 基础：名称、分类、默认页大小、连接池、备注（预览按钮保留）；
2. SQL：编辑器（Tab 缩进/格式化/高亮/「预览未保存 SQL」按钮保留），结果名称输入保留；
3. 输出护栏：允许全量输出 + max_rows + `allow_write`（条件显示逻辑保持）；
4. 调度与保活：现两折叠区并入本分区（完整任务管理仍链向 `/config/scheduler`）；
5. API 端点：列表+新建入口（表单细节在端点页）；
6. Sticky 底栏：保存 / 保存并关闭 / 取消 + 未保存提示。

### 4.5 API 接口（`/config/api-endpoints`）

- 页头：标题 + 新建；筛选（按名称/报表）；
- 行卡片：名称+路径、关联报表、状态、主 URL+复制；展开显示全量 URL、静态 URL、说明摘要；
- 操作：启停（toggle 样式）、编辑、复制 URL、删除（入确认弹层）；
- Key 管理保持「主 form 外」结构约定。

### 4.6 定时任务（`/config/scheduler`）

1. 页头：标题 + 新建任务按钮；全局停用横幅置顶（人话：「定时调度当前为停用状态，任务仅保存不执行」）；
2. 列表：任务名、绑定报表数（hover 明细）、计划摘要（每 60 分钟 / 每天 09:00）、下次执行、上次结果（成功耗时/失败）、熔断与审计徽标、🔇→「含静默窗口」文字标；
3. 行操作：立即执行 / 启停 / 编辑（进表单页）/ 删除；
4. 新建/编辑表单页：沿用现字段，排除规则编辑器组件化（分组树 + 规则行）。

### 4.7 审计（`/audit`）

- 统一筛选条组件：类型、日期范围（快捷 chips：今天/近7天/近30天/自定义）、用户、关键字；
- 操作区：导出 CSV、清理（危险按钮分级）；
- 表格、分页、行高亮沿用通用表格组件。

### 4.8 概览（`/config`）

- 统计行：报表数、分类数、API 数、启用调度数（小卡片）；
- 快捷入口：六格（报表配置/连接池/用户/API/定时/审计）→ 与侧栏同路由；
- 系统状态：调度开关状态、缓存状态、存储引擎（SQLite/MySQL）只读信息；
- 首部署空态：保留三步引导（文案迁入）；
- DEBUG 测试数据导入卡保留（仅 DEBUG）。

## 5. 交互收敛决策（解决 P2 与三套筛选）

| 现状 | 新方案 |
|------|--------|
| 列头快速筛选 + 嵌套构建器 + 规则 JSON 复制/应用（三套） | **两层模型**：列头快速筛选（轻）+ 「高级筛选」抽屉（嵌套构建器与规则预览合并）；规则 JSON 导入/导出收进抽屉工具菜单 |
| 筛选帮助 `?` 多入口 | 全站统一「帮助」抽屉，内容源仍是 `filter_help.py` |
| 导出藏「更多选项▾」 | **统一导出对话框**：格式/字符集/智能引号/ZIP/列范围（应用当前列设置）一次呈现；导出按钮唯一入口 |
| 字段/排序面板 `display` 硬切 | 统一「右侧抽屉」组件：遮罩 + ESC + 焦点圈闭 + 底部应用 |
| 备注三态 自动/展开/折叠 | 普通折叠（有内容默认展开），按报表记忆保留 |
| confirm 手写/组件双轨 | 统一确认弹层组件（文案模板：动词+对象+影响范围），仍无第三套框架，基于现有 build 模式收敛 |
| 术语直出（prefer_cache、直连 MySQL…） | 术语表翻译（T4）：「缓存正常/已过期将自动刷新/缓存不可用已直连数据库」等 |
| 批量按钮常驻 | 选中浮出批量条（与 4.3 一致） |
| loading 仅报表页 | 全站统一提交遮罩（所有 POST 表单），导出下载除外（保持直接下载） |
| 状态仅靠颜色 | 状态点+文字双编码 |

## 6. 「去向」词汇表（回填清单用）

| 值 | 含义 |
|----|------|
| 保留 | 功能与位置语义不变，仅视觉/组件换装 |
| 重构→X | 功能保留，页面/区块重组到 X |
| 移位→X | 从 A 页面移到 X 页面 |
| 拆分→X | 原混合页拆出到 X |
| 合并→X | 多个入口/组件合并进 X |
| 删除（含理由） | 交互形态废除，功能由新形态承接 |
| 保持（非 UI） | 后端/协议能力，UI 不呈现 |
